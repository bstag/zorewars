Build your first warrior

  1. Start with one-shot. Its seq group runs the comparison scanner first, then hands the position it found to a core clear.
  2. Select a block to read what it does and edit its parameters. To add a block, select a + slot and click a block from the library. On desktop, you can also drag blocks onto the slots. To move a block by touch or keyboard, select it, choose Move to slot, then choose a slot.
  3. Try a different structure with New stack. An opening hands off to the next member in seq. A body keeps running, so use par for bodies that can safely run side by side. boot copies a body away from its starting location. Groups can contain other groups.
  4. Choose Build warrior. The linker checks that the blocks fit and the simulator runs behavior checks. A successful check means the design does what the checked contracts expect in those scenarios. The library benchmark measures how it fights.
  5. Try one opponent or the whole compatible library. Use the same seed and round count to compare two edits. A win is worth 3 points and a tie is worth 1. Increase rounds for a closer comparison.

The selected battlefield, rules and length budget affect which blocks and library warriors can run.

Save JSON to keep editing your stack or pass it to node scripts/algebra.js build with the same rules and length. Save the .red file to drop into the Arena. Keep a JSON copy before loading another recipe or closing the page.
